# Paradise Nursery Shopping Application

Paradise Nursery is an online plant and garden hardware store web application.  
This project was developed as part of the Final Project assignment to demonstrate skills in React, Redux, and modern web development practices.

## 🌱 Features
- Home page with background image and company branding
- Product listing by category (plants, tools, accessories)
- Each product includes thumbnail, name, and price
- Buttons for:
  - View Details
  - Add to Cart
  - Remove from Cart
  - Checkout
  - Back to Home
- Shopping cart with dynamic total
- About Us page with company details and team members
- Contact Us page with contact information and form

## 🛠️ Tech Stack
- React.js
- Redux (for cart state management)
- CSS for styling
- GitHub Pages / Netlify for deployment
